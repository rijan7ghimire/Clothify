Setup Instructions

Prerequisites

  • Visual Studio 2022 (Community/Professional/Enterprise)
  • "ASP.NET and web development" workload installed
  • SQL Server Express LocalDB (included with Visual Studio)

Steps to Run

  1. Open Clothify.sln in Visual Studio 2022.
  2. In Solution Explorer, right-click the App_Data folder → Add → SQL Server Database.
  3. Name it ClothifyDB.mdf and click OK.
  4. Double-click ClothifyDB.mdf in App_Data to open it in Server Explorer.
  5. Right-click on the database connection → New Query.
  6. Open SQL/Database.sql, copy the entire script, paste it into the query window, and execute (Ctrl+Shift+E).
  7. Press F5 (or click Start) to run the application.
  8. The application will open in your default browser.
Note: The connection string in Web.config uses AttachDbFilename with LocalDB. No external SQL Server installation is required. The database file is stored in the App_Data folder.

Features

Customer Features

  • User Registration & Login with password hashing
  • Product Catalog with category filtering & search
  • Product Detail with ratings & reviews
  • Shopping Cart (add, remove, update quantity)
  • Checkout with Nepal shipping address & multiple payment methods
  • Order History with status filtering
  • Order Tracking with visual timeline
  • Order Cancellation (for pending orders)
  • Wishlist (save products for later)
  • Customer Feedback & Ratings (1-5 stars)
  • Profile Management (edit profile, change password)
  • Notifications page for order updates
  • Email notifications on order placement

Admin Features

  • Admin Dashboard with statistics overview
  • Manage Users (view, update role, delete)
  • Manage Products (CRUD operations)
  • Manage Categories (CRUD operations)
  • Manage Orders (update status: Placed/Processing/Shipped/Delivered/Cancelled)
  • Manage Feedback (view, filter by rating, delete)
  • Sales Reports & Analytics Dashboard
  • Email notification on order status change

Technical Features

  • Mobile-first responsive design
  • ASP.NET Forms Authentication & Authorization
  • ASP.NET Web Forms User Controls (.ascx)
  • Advanced controls: Repeater, DataList, GridView, DetailView
  • Data binding with parameterized SQL queries
  • Client-side & server-side form validation
  • Session-based shopping cart
  • Secure password hashing with BCrypt
  • Master Pages for consistent layout
  • Proper file organization & naming conventions

Browser Compatibility

This application has been designed and tested to work across all modern browsers:

  • Google Chrome Recommended
  • Microsoft Edge
  • Mozilla Firefox
  • Opera
  • Safari (macOS/iOS)

The application uses standard HTML5, CSS3, and JavaScript (ECMAScript) for maximum compatibility. Mobile-first design ensures optimal viewing on smartphones and tablets.
